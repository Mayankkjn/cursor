# cursor

## Onboarding flow prototype

`onboarding/` contains a static, vanilla HTML/CSS/JS mobile mockup of the Finny fintech app's
20-screen onboarding flow (welcome, phone/name capture, PAN/Aadhaar/bank KYC, account
aggregation, income & expense capture, and the FIRE number/age reveal). Open
`onboarding/index.html` in a browser to try it — the phone-frame mockup supports tapping through
each screen's own button as well as the prev/next controls below it.
