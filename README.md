# cursor

## Onboarding flow prototype

`onboarding/` contains a static, vanilla HTML/CSS/JS mobile mockup of the Finny fintech app's
31-screen onboarding flow: emotionally-led splash screens, sign-up, a solo-or-partner choice,
an explanation of the FIRE (Financial Independence, Retire Early) concept, net-worth discovery
(PAN, account aggregator connections, other assets/inheritance), income & expense capture, the
FIRE age/number reveal with interactive what-if sliders, and a plan/advisor + feature tour close.
Open `onboarding/index.html` in a browser to try it — the phone-frame mockup supports tapping
through each screen's own controls as well as the prev/next controls below it.
